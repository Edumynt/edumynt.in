# Edumynt Expo App

The native app lives in `edumyntinapp/` and is an Expo SDK 55 app. It does not duplicate course content. It consumes the static JSON API generated by this Astro site.

## Connection Contract

- Astro content source: `src/content/courses/**`
- API serializer: `src/lib/api-data.ts`
- Static API routes: `src/pages/api/**`
- Mobile API client: `edumyntinapp/lib/api.ts`
- Mobile local storage: `edumyntinapp/lib/storage.ts`

The mobile app defaults to:

```text
https://edumynt.in
```

Override it for local or preview testing:

```bash
EXPO_PUBLIC_EDUMYNT_API_BASE=http://localhost:4321 npm start
```

## App Screens

- `app/(tabs)/index.tsx`: Home, continue lesson, recent courses, published courses.
- `app/(tabs)/courses.tsx`: Course listing with search, exam filter, and difficulty filter.
- `app/(tabs)/search.tsx`: Search over the static API search index.
- `app/course/[courseId].tsx`: Course detail with Curriculum, Overview, and Details tabs.
- `app/lesson/[...path].tsx`: Full-screen lesson reader with progress bar and next lesson action.

Lesson screens intentionally live outside `(tabs)` so the bottom tab bar is hidden in the reader.

## Validation

Run from `edumyntinapp/`:

```bash
npm run typecheck
npm run doctor
```

Run from the repository root after API changes:

```bash

```
