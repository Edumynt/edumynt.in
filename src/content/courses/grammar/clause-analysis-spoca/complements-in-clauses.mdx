# Complements in Clauses

## Opening Hook

Compare these two sentences:

- "She called her friend."
- "She called her friend brilliant."

In both sentences, **her friend** is the object. But in the second one, one more element is doing an important job.

> **Think about it:** Is *brilliant* receiving the action, or describing the object?

Complements are one of the most misunderstood clause elements.

Learners often see a noun or adjective after a verb and call it an object. But sometimes that element does not receive an action. It **describes**, **identifies**, or **renames** something.

That is a **Complement**.

---

## Subject Complement

A **Subject Complement** comes after a linking verb and tells us something about the subject.

Examples:

- "Neha is **a doctor**."
- "The sky became **dark**."
- "The soup tastes **delicious**."

Here:
- **Neha** is **a doctor**
- **The sky** became **dark**
- **The soup** tastes **delicious**

The complement is not an object. It does not receive the action. It gives information about the subject.

---

## Linking Verbs

Subject complements are common after linking verbs such as:

- be
- become
- seem
- appear
- feel
- taste
- look
- remain

Example:

- "The child seems **tired**."
- "The road remained **empty**."

---

## Object Complement

An **Object Complement** gives information about the object.

Examples:

- "They elected him **captain**."
- "The news made her **anxious**."
- "We painted the wall **blue**."

In each sentence:
- there is an object first
- then something tells us what that object became or how it is characterized

So in "We painted the wall blue":
- **the wall** = Object
- **blue** = Object Complement

---

## Object vs Complement

Compare these pairs:

### Pair 1
- "She called **her friend**." → object only
- "She called **her friend** **brilliant**." → object + complement

### Pair 2
- "He became **angry**." → subject complement
- "He hit **the door**." → direct object

The test is simple:

- Does the element receive the action? → Object
- Does the element rename/describe subject or object? → Complement

---

## Hindi Comparison

Hindi often makes the meaning obvious, but English requires careful verb pattern analysis.

**"वह डॉक्टर है।"** → "He is a doctor."  
Here **a doctor** is not something he *does*. It identifies him. So it is a **Subject Complement**.

**"उन्होंने उसे कप्तान चुना।"** → "They elected him captain."  
Here **captain** tells us what *him* became. So it is an **Object Complement**.

## Practice

Identify the complement type:

1. "The room looks clean."  
   - **clean** = Subject Complement

2. "They made Rahul monitor."  
   - **Rahul** = Object  
   - **monitor** = Object Complement

3. "My grandmother is very kind."  
   - **very kind** = Subject Complement

4. "The joke made us happy."  
   - **us** = Object  
   - **happy** = Object Complement

> **Think about it:** In "She is a teacher," is *a teacher* receiving an action?

No. It identifies the subject. So it is a complement.

---

## Key Takeaways

1. Complements complete meaning by describing or identifying.
2. Subject complements refer back to the subject.
3. Object complements refer back to the object.
4. Do not confuse complements with objects.
