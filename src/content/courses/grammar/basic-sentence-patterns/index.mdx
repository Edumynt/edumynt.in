# Basic Sentence Patterns

Welcome to the most important chapter in English grammar.

Here's why: **every sentence in English** — every text message, every email, every novel, every news article — is built from just **7 basic patterns**. Master these, and you understand the architecture of the entire language.

## What You'll Learn

| Lesson | Pattern | What You'll Master |
|---|---|---|
| 1 | What is a sentence? | Subject, predicate, sentence types |
| 2 | SV (Subject + Verb) | Intransitive verbs, simplest pattern |
| 3 | SVO (Subject + Verb + Object) | Transitive verbs, Hindi vs English word order |
| 4 | SVOO (S + V + Indirect O + Direct O) | Two-object patterns, ditransitive verbs |
| 5 | SVC (S + Linking V + Complement) | Linking verbs, the "equals sign" pattern |
| 6 | SVOC (S + V + O + Object Complement) | Object complements, describing the object |
| 7 | SVA & SVOA (Adverbial patterns) | Required adverbials, where/when/how |
| 8 | Pattern Detective | Analyze any sentence, error correction |
